# WHU-MARS / UAD：CLIP-ViT-B/16 A800 单卡实验启动手册

## 1. 本轮实验边界

本轮只执行 `2.CLIP_ViT_B16替换ViT迁移方案_0920.md` 中的 B、C、D、E 四组。Group A 是上一轮已经完成的 ImageNet ViT-B/16 Full UAD，不重复训练。

| Group | 配置 | Backbone | UAD | Normalization | Backbone LR | 新层 LR | 作用 |
|---|---|---|---|---|---:|---:|---|
| B | `configs/clip_baseline.yml` | CLIP ViT-B/16 | × | 0.5 / 0.5 | 0.0008 | 0.008 | CLIP 初始化本身 |
| C | `configs/clip_uad.yml` | CLIP ViT-B/16 | ✓ | 0.5 / 0.5 | 0.0008 | 0.008 | 主推荐路线 |
| D | `configs/clip_uad_imagenet_norm.yml` | CLIP ViT-B/16 | ✓ | ImageNet | 0.0008 | 0.008 | normalization 对照 |
| E | `configs/clip_uad_lr008.yml` | CLIP ViT-B/16 | ✓ | 0.5 / 0.5 | 0.008 | 0.008 | fine-tuning LR 对照 |

本轮不使用 CLIP text encoder、prompt、image-text loss、CLIP normalization、bicubic 位置插值或 512D projection。训练与评测特征均为 `ln_post` 后、projection 前的 768D CLS visual feature。

## 2. 固定实现口径

1. 输入固定为 `[256, 128]`，patch size 和 stride 均为 `[16, 16]`，目标 patch grid 为 `16×8`。
2. CLIP checkpoint 的 `14×14` patch positional embedding 使用 bilinear 插值到 `16×8`；CLS positional embedding 不插值。
3. CLIP visual encoder 使用原始 `ln_pre`、12 层 residual attention、QuickGELU 和 `ln_post`。不加载或使用 `visual.proj`。
4. RGB、NIR、Thermal 仍由 `Image.open(...).convert("RGB")` 读入；不增加模态专用预处理。
5. Group B/C/D 的 CLIP backbone 使用 `SOLVER.BACKBONE_LR=0.0008`，BNNeck/classifier 等新层使用 `SOLVER.BASE_LR=0.008`。warm-up 和 cosine decay 对各参数组按各自初始 LR 等比例执行。
6. Group E 使用 `SOLVER.BACKBONE_LR=0.008` 与 `SOLVER.BASE_LR=0.008`。
7. Group C/D/E 的损失固定为 `CE + WRT + 0.01 ProCA + 1.0 GPD`；`GPD_MOMENTUM=0.2` 表示 `0.8×old + 0.2×new`。
8. `SOLVER.IMS_PER_BATCH=64` 是逻辑样本数；三模态拼接后实际前向 192 张图像，不得改成 192。
9. 每组独立单卡运行：`CUDA_VISIBLE_DEVICES=0`、`WORLD_SIZE=1`、`MODEL.DIST_TRAIN=False`。同一时刻只运行一组。
10. 正式报告固定采用 epoch 120，不按每 10 epoch 的 test split 结果挑选 checkpoint。

## 7. 验收与停止条件

每组至少确认：

1. 日志实际进入 `Epoch[1]`，不是只有 shell、配置或预检成功；
2. 训练完成 epoch 120 并生成对应 `transformer_120.pth`；
3. 自动评测与独立复评的 mAP、Rank-1、Rank-5、Rank-10 在合理浮点误差内一致；
4. B↔C 只改变 UAD，C↔D 只改变 normalization，C↔E 只改变 backbone LR；
5. 日志中不得出现 512D feature，模型 pre-BN feature dimension 应为 768；
6. 出现 NaN/Inf、CLIP 权重缺失、位置编码不是 `14×14 -> 16×8`、实际 loss type 不符或输出目录不符时，立即停止当前组并保留原始日志；
7. 若 Group E 在早期明显发散，不自动降 LR 或改变梯度裁剪；保留失败作为全 LR 对照结果；
8. 比较时重点报告 A↔C、B↔C、C↔D、C↔E 的 matched delta。单 seed 结果不宣称统计显著性。

每 10 epoch 的 test split 指标只能用于运行健康检查。如从这些中间结果观察最优 checkpoint，必须标记为 `test-selected exploratory screening`，不能替代 epoch 120 正式结果。

# WHU-MARS / UAD：统一公平基线 A800 单卡实验启动手册

## 1. 实验边界

本手册执行 `5.统一公平基线实验方案_0920.md` 中的 9 组实验：

- V1–V4：重新训练 UAD 四组消融；
- C1–C5：重新训练 CLIP 迁移实验；
- 每个实验为独立 `WORLD_SIZE=1` 单卡任务；
- 推荐严格按 V1→V4→C1→C5 串行执行；
- 不覆盖旧实验输出。

不要在当前代码上重新执行 `run_baseline_a800.sh`、`run_uad_a800.sh` 或旧版 `run_clip_*.sh` 并将其视为历史复现；这些脚本会继承当前已修正的共享代码。历史口径需要使用提交 `93d3587`，本轮只能使用 `run_fair_*.sh`。

## 6. 每组启动后的检查

日志开头必须核对：

```text
DROP_PATH: 0.1
SEED: 1234
Isolated RNG seeds: backbone_init=1235 shared_head=1236
Isolated data RNG seeds: sampler=1334 train_workers=1434
Using per-group LR scheduler
```

同时核对该组的：

- `LOSS_TYPE`；
- `BACKBONE_LR`；
- `PIXEL_MEAN` / `PIXEL_STD`；
- 输出目录；
- CLIP 组的 `Loaded CLIP ViT-B/16 visual weights`；
- CLIP 组的 `CLIP DropPath rates: first=0.000000 last=0.100000 layers=12`；
- 实际进入 `Epoch[1]`。

出现 NaN/Inf、权重缺失、DropPath 首尾不是 0/0.1、随机种子日志不符或 loss 配置不符时，停止当前组并保留原始日志。

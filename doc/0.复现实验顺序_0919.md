# 3. 阶段 1：复现 Unified Baseline

这是整篇论文最关键的第一个复现目标。

## 3.1 Baseline 结构

论文中的 Unified Baseline：

```text
RGB / NIR / TIR
       ↓
   Shared ViT-Base
       ↓
  Pre-BN Feature f
       ↓
      BNNeck
       ↓
  Post-BN Feature z
```

所有模态共享：

- 同一个 Backbone
- 同一个 BNNeck
- 同一个 Classifier

没有：

- ProCA
- GPD
- 多模态独立分支
- 模态专用 Head
- Pairwise Alignment

---

## 3.2 Baseline Loss

基础损失：

\[
L_{base} = L_{ce} + L_{WRT}
\]

其中：

### Cross Entropy

作用于 BN 后特征：

\[
z = BN(f)
\]

即：

\[
L_{ce}(z)
\]

### Weighted Regularization Triplet Loss

作用于 BN 前特征：

\[
L_{WRT}(f)
\]

### 推理

推理时使用：

\[
\hat f = \frac{f}{\|f\|_2}
\]

即：

> 使用 L2 Normalized 的 Pre-BN Feature 进行检索。

---

## 3.3 P×M×K Sampler

论文 baseline 已经使用：

\[
P \times M \times K
\]

采样器。

实验设置：

\[
P=16,\quad M=3,\quad K=4
\]

即每个 Batch：

- 16 个身份
- 每个身份 3 个模态
- 每个身份每个模态 4 张图像

因此：

\[
16 \times 3 \times 4 = 192
\]

即：

```text
Batch Size / GPU = 192
```

示意：

```text
PID 1:
    RGB × 4
    NIR × 4
    TIR × 4

PID 2:
    RGB × 4
    NIR × 4
    TIR × 4

...

PID 16:
    RGB × 4
    NIR × 4
    TIR × 4
```

# 4. 阶段 2：复现 Baseline + ProCA

此阶段只加入 ProCA：

\[
L =
L_{base}
+
0.01L_{ProCA}
\]

暂时不要加入 GPD。

---

## 4.1 计算 Sample Feature

对于 Identity \(y\)、Modality \(m\)：

\[
f^y_{m,k}
\]

首先执行：

\[
L2Norm(f^y_{m,k})
\]

---

## 4.2 计算 Modality Center

对于每个身份、每个模态：

\[
\tilde{\mu}_{y,m}
=
\frac{1}{K}
\sum_{k=1}^{K} f^y_{m,k}
\]

然后：

\[
\mu_{y,m}
=
norm(\tilde{\mu}_{y,m})
\]

当：

\[
P=16,\quad M=3
\]

时，一个 Batch 应产生：

\[
16 \times 3 = 48
\]

个 Modality Centers。

建议调试：

```text
modality_center.shape
≈ [48, feature_dim]
```

---

## 4.3 计算 Identity Center

对 RGB / NIR / TIR 三个中心再求平均：

\[
\tilde{\mu}_y
=
\frac{1}{3}
(
\mu_{y,RGB}
+
\mu_{y,NIR}
+
\mu_{y,TIR}
)
\]

然后：

\[
\mu_y
=
norm(\tilde{\mu}_y)
\]

一个 Batch 应得到：

\[
16
\]

个 Identity Centers。

重要：

> Identity Center 在 ProCA Loss 中作为 Stop-Gradient Anchor。

---

## 4.4 ProCA Loss

\[
L_{ProCA}
=
\frac1P
\sum_y
\frac1{|\mathcal M|}
\sum_m
\|\mu_{y,m}-\mu_y\|_2^2
\]

其目标是：

```text
RGB Center ─┐
NIR Center ─┼→ Identity Center
TIR Center ─┘
```

即：

> 让同一个身份的不同模态特征更加集中。

---

## 4.5 ProCA 复现目标

论文 Table 8：

| Method | mAP | Rank-1 | Rank-5 | Rank-10 |
|---|---:|---:|---:|---:|
| Baseline | 8.9 | 23.9 | 41.4 | 50.5 |
| Baseline + ProCA | 9.3 | 24.5 | 42.0 | 50.7 |

预期提升：

\[
mAP: +0.4
\]

\[
Rank\text{-}1: +0.6
\]

因此：

> ProCA 单独提升较小是论文中的正常现象。

# 5. 阶段 3：复现 Baseline + GPD

此阶段重新从 Baseline 出发：

\[
L =
L_{base}
+
L_{GPD}
\]

暂时不加入 ProCA Loss。

---

## 5.1 建立 Global Prototype Memory

训练集有：

\[
N_{ID}=500
\]

个 Identity。

维护：

\[
P \in R^{N_{ID}\times d}
\]

即：

```text
prototype_memory.shape
=
[num_train_ids, feature_dim]
```

每个 Identity 对应一个 Prototype。

---

## 5.2 计算 GPD Loss

对当前 Batch 的 normalized feature：

\[
F \in R^{B\times d}
\]

与 Prototype Memory：

\[
P \in R^{N\times d}
\]

计算：

\[
logits
=
\frac{FP^T}{\tau}
\]

其中：

\[
\tau = 0.03
\]

得到：

\[
[B,N]
\]

的分类 logits。

之后：

\[
L_{GPD}
=
CrossEntropy(logits,pid)
\]

伪代码：

```python
f = normalize(f)
p = normalize(prototypes)

logits = f @ p.T / tau
loss_gpd = cross_entropy(logits, pid)
```

---

## 5.3 Prototype EMA 更新

论文使用：

\[
p_y
\leftarrow
norm
\left(
\alpha p_y
+
(1-\alpha)\mu_y
\right)
\]

其中：

\[
\alpha=0.8
\]

即：

```text
80% Old Prototype
+
20% Current Identity Center
```

---

## 5.4 注意更新顺序

论文描述顺序为：

```text
1. Forward
2. 使用旧 Prototype 计算 GPD
3. 计算当前 Batch 的 Identity Center
4. 进行当前 Iteration 的训练
5. 使用 EMA 更新 Prototype Memory
```

重点：

> 当前 Iteration 的 GPD 使用的是“更新前”的 Prototype。

---

# 6. 阶段 4：完整复现 Full UAD

完整目标函数：

\[
L_{UAD}
=
L_{ce}
+
L_{WRT}
+
0.01L_{ProCA}
+
1.0L_{GPD}
\]

完整流程：

```text
                         ┌──────────────→ CE
                         │
RGB/NIR/TIR → ViT → f → BN → z
                  │
                  ├──────────────→ WRT
                  │
                  ├→ Modality Centers
                  │        ↓
                  │  Identity Centers
                  │        ↓
                  │      ProCA
                  │
                  └→ Identity Centers
                           ↓
                      EMA Update
                           ↓
                  Global Prototypes
                           ↓
                          GPD
```

ProCA 与 GPD 的联系：

```text
Sample Features
      ↓
Modality Centers
      ↓
Identity Center
      ↓
EMA
      ↓
Global Prototype
```

因此：

> ProCA 不只是额外提供一个 Loss，它产生的 Identity Center 还负责更新 GPD 的 Prototype Memory。

# 12. 阶段 10：复现 3×3 Modality Matrix

|---|---|---|---|

该实验非常适合用于后续研究分析：

```text

```

因为这些通常是更困难的 Cross-Spectral 场景。
